# TaskControl — frontend

Русскоязычное приложение для планирования и контроля выполнения задач. Реализовано по исходной светлой палитре Figma: молочный фон, тёмный текст, оранжевые акценты, Roboto и Roboto Condensed. Главная страница показывает интерактивный процесс работы; кабинет сохраняет быстрые спокойные переходы.

На первом экране главной карточки задач собираются в круг и арку и садятся на доску проекта. Ниже — «Возможности» стопкой карточек, карусель «Как это работает» ([открыть](http://127.0.0.1:8080/#process)) и роли команды. Есть светлая и тёмная темы.

Код и стили устроены так же, как в корневом `frontend/`: публичная главная — в `src/pages/landing/`, стили кабинета — в `src/styles/`, их порядок задаёт `src/styles.css`.

## Подключение

Кабинет по умолчанию использует Django. Порядок запуска, демонстрационные учётные записи и описание базы находятся в [README проекта](../README.md). Адрес сервера для прокси Vite задаётся переменной `TASKCONTROL_BACKEND_URL`, по умолчанию используется `http://127.0.0.1:8000`.

Адаптер ответов Django находится в `src/data/django.ts`. Для автономного показа интерфейса можно перед запуском установить `VITE_DEMO_MODE=true`. Этот режим использует данные браузера и подходит для существующих тестов локального прототипа.

Тема сохраняется в браузере под ключом `taskcontrol.theme.v1` и применяется до запуска React. Карта экранов доступна через «Помощь».

## Проверки

```sh
npm run typecheck
npm run lint
npm run test
npm run test:e2e
npm run build
```

Сквозные проверки используют установленный Microsoft Edge в headless-режиме. Для другого компьютера можно изменить `channel` в `playwright.config.ts` или установить Chromium через Playwright. Отчёт: `playwright-report/index.html`. Проверки создают изолированные контексты браузера и не меняют данные пользовательского профиля.

Статическая production-сборка создаётся в `dist/`; `npm run preview` запускает её локально. При будущем размещении сервер должен отдавать `index.html` для frontend-маршрутов. Размещение в интернете в этой задаче не выполняется.
